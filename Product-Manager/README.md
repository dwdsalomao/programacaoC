# Product Manager

A simple console-based product and inventory management system developed in C.

This project was created as part of my journey to learn and practice C programming.

## Features

- Add products
- List registered products
- Search products by code
- Add or remove stock
- Calculate the total inventory value
- Validate stock quantities and product prices
- Limit the number of registered products

This project helped me practice:

- `if / else`
- `switch`
- `for` loops
- `do-while` loops
- `scanf` and `fgets`
- String manipulation
- Searching through arrays
