# Money! Bank

A simple bank account simulator developed in C as a programming learning project.

## About the Project

Money! Bank is a console-based bank simulator developed to practice fundamental C programming concepts.

The program allows the user to:

- Check the account balance
- Make deposits
- Make withdrawals
- View the transaction statement
- Exit the program

## Features

- Balance management
- Deposit and withdrawal validation
- Transaction history
- Input validation
- Transaction limit
- Console-based menu
- Structured transaction records

## Concepts Practiced

This project was developed while studying C programming and applies concepts such as:

- Variables and data types
- `if`, `else if`, and `else`
- `switch`
- `do...while`
- `for`
- Arrays
- Structures (`struct`)
- Functions from `stdio.h`
- Input validation with `scanf`
- Constants with `#define`
- Basic data organization
